# 安心伴

> 面向 Android 的陪伴聊天原型：大字界面、本地对话与记忆，以及 MiniMax 模型接口。

**技术栈：** Java / Kotlin · Android · MiniMax Chat Completions

**使用边界：** 陪伴工具不替代医疗、心理咨询或紧急救助。

---

一款面向安卓手机的 MiniMax 陪伴聊天应用原型。它的定位是像朋友一样进行日常陪伴、轻松聊天和心情放松推荐，不替代医生、心理咨询师或紧急救助。

## 主要功能

- 大字号聊天界面
- 接入 MiniMax OpenAI 兼容接口，兼容 `https://api.minimaxi.com/v1/chat/completions` 和 `https://api.minimax.io/v1/chat/completions`
- 支持在手机里本地保存 MiniMax API key
- 默认使用 `MiniMax-M2`
- 提供独立每日推荐页：今日新闻、开心一下、心灵鸡汤
- 支持手写输入和语音输入切换，通过手机已安装的中文输入法完成，不依赖 Google 语音服务
- 对话记录保存在手机本地
- 每隔几轮聊天自动整理长期记忆，记录用户明确分享的人名、家庭关系和重要事件
- 支持查看和清空本地记忆
- 检测到“想死”“不想活”“自杀”等高风险表达时，优先提示联系身边家人和急救支持

## 使用方法

1. 用 Android Studio 打开这个文件夹。
2. 等待 Android Studio 同步 Gradle。
3. 连接安卓手机，或创建模拟器。
4. 点击 Run 安装到手机。
5. 打开应用，点“设置密钥”，填入 MiniMax API key。

建议为这个应用单独创建一个 MiniMax key，设置较低额度，并定期轮换。不要把 key 写进代码或截图发给别人。

## 家人使用提醒

这个应用适合做温柔陪伴和情绪稳定辅助。若使用者出现以下情况，请优先联系家人、医生或当地急救电话：

- 明确说“不想活”“想死”“活不下去”
- 有自伤准备或已经自伤
- 连续拒绝吃饭、喝水或服药
- 出现明显意识混乱、幻觉、妄想
- 情绪突然极端激动或极端低落

家人的陪伴很重要。软件可以补充陪伴，但不能替代真实的人在身边。
